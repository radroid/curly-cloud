# private/

Everything in this folder except this README is gitignored.

- `answers/` — exports from `interview/raj-interview.html` waiting to be ingested (or already ingested).
- `question-packs/` — follow-up questions generated from your answers, to import back into the interview stack.
- `evals/` — golden cases about private answers (`*.json`, same shape as `evals/golden.json`).

Raw answers only ever live here on your machine and in the D1 database.
